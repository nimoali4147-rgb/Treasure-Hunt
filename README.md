# 🏴‍☠️ Treasure Hunt

This is a Treasure Hunt game, Where Players explore different locations, search specific areas, discover treasures, collect points, and view their game information.


## 🎮 Game Features

- Player registration
- Location selection
- Area selection
- Treasure searching
- Random treasure discovery
- Treasure collection
- Score tracking
- Game history
- View collected treasures
- Explore multiple locations
- Game menu
- Game Over
- Persistent data storage using SQLite


## 🗺️ Locations

The game contains four locations:

1. Forest
2. Cave
3. Island
4. Desert

Each location contains different areas that the player can search.

### Forest
- Old Tree
- River Bank
- Abandoned Cabin

### Cave
- Dark Tunnel
- Rock Corner
- Old Chest

### Island
- Beach
- Palm Tree
- Shipwreck

### Desert
- Sand Dune
- Desert Camp
- Ancient Ruins


## 💎 Treasures

The game contains different treasures with different point values.

| Treasure | Points |
|----------|-------:|
| Golden Coin | 100 |
| Silver Coin | 50 |
| Diamond | 250 |
| Ancient Necklace | 150 |
| Ruby | 200 |
| Empty Chest | 0 |
